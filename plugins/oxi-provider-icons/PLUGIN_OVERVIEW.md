# OXI Provider Icons

Local theme-aware marks for seven public-safe OXI agent provider ids, drawn
through BB's shared provider icon resolver in the model picker and the
builtin provider usage header. Every mark uses the native BB mask-span
pattern, so it never disturbs the host's touch hit-testing.

Plugin ID: `oxi-provider-icons`. Requires BB 0.50.1+. Built-ins
(`codex`, `claude-code`, `acp-cursor`), Grok and unknown ids keep the host
artwork; disabling the plugin restores it everywhere. Presentation-only: no
settings, storage, network or backend surface. See [README](./README.md) for
the registry, licensing and development checks.
