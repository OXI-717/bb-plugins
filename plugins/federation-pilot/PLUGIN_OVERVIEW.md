Use projects on independent BB servers from the ordinary thread tree.

Configure each connection with a label, remote project, existing bridge machine and SSH profile. Remote chats retain their original provider and environment. A standard Network icon shows connectivity. New threads use the selected remote project and environment.

Disabled and read-only by default. Experimental: tested with BB 0.46.0/0.46.1. Files, attachments, terminals and other plugins' actions are not federated. Ordinary agent tools and the BB CLI still address their own server. See README for setup, permissions and limitations.
