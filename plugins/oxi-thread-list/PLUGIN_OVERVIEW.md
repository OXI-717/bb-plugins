# OXI Session Tree

Optional project-first machine groups for BB's session tree. Includes a global
switch, per-project overrides and independent collapse state. Children remain
under their parent even when they run on a different host.

Plugin ID: `oxi-thread-list`. Requires BB 0.49+. The bundled list remains
available as a fallback. See [README](./README.md) for selection, settings,
preference import, performance boundaries and development checks.
