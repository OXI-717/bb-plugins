# BB Projects

Project-scoped GitHub, Linear and Jira tasks; repository/account connections;
side-panel task links; and native agent-session preparation with explicit model
and environment choice. Optional memory, autopilot and TaskNotes integrations
start disabled and are enabled through settings.

Plugin ID: `oxi-projects`. Distribution: immutable `oxi-projects/vX.Y.Z` tags in
this public repository. Requires BB 0.46+. See [README](./README.md) for setup,
CLI commands, integration requirements and development checks.
