# VPN Guard

Observe trusted host-local VPN state and hold protected BB work on explicitly selected machines when the state is disconnected or unknown. Enforcement is off by default. Codex, Claude, Cursor and Devin are in scope; Kimi and Z.ai remain available.

An optional, separately acknowledged setting can suspend the native Codex and Claude plugins globally. Existing connections and bridge processes are not proven stopped. See [operations and limits](docs/operations.md) before enabling.
