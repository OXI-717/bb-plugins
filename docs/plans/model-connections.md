# Separate model chooser

The accepted scope is a standalone BB plugin, not a core modification or a second model gateway. A header action and native side panel group configured providers by actual local versus supported pooled routing. The main chooser excludes confirmed missing installations and unknown local authentication; those rows remain available in a collapsed section for inspection. Visibility preferences are per execution machine and do not affect other BB surfaces or provider policy.

The native controlled model picker owns catalog behavior. Existing-thread changes use the SDK model/reasoning update on the next turn. Cross-provider continuation uses an explicit native new-thread composer seeded with the source reference, workspace and reviewed model. A bounded creation journal prevents duplicate dispatch after uncertain replies. No old threads are resumed or stopped by installation.

Validation covers grouping, exact-ID deduplication, unavailable state, per-thread bypass, target-machine routing, stale configuration rejection, hiding without disable, unchanged native submission inputs, repeat creation and reload. UI checks include mobile width, overflow, keyboard controls, refresh failure, and explicit new-thread submission. Publish and install this plugin independently from the busy Account Pooler so the chooser does not require an outage.
